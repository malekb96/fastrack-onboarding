Use the **auto-learn** skill to capture and persist a learning from this session.

Determine what was discovered:
1. **Pitfall / error** → `learnings/pitfalls.md`
2. **Better pattern** → `learnings/patterns.md`
3. **User correction / preference** → `memory/feedback_*.md` + possibly a skill update
4. **New project data** (IDs, choice values) → `CLAUDE.md`
5. **Wrong/incomplete skill instructions** → update the skill's `SKILL.md` directly

Write the entry immediately, confirm to the user which file was updated.
